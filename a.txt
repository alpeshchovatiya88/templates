# Exploratory Data Analysis (EDA)

## Overview

This folder contains the exploratory data analysis performed for the **Smart Mortgage Insurance (SMI)** project.

The objective of this analysis is to understand the characteristics of mortgage loans, identify key risk drivers, assess feature relationships, detect potential bias, and generate insights that support predictive model development.

---

## Analysis Performed

### 1. Initial Exploratory Data Analysis
**File:** `smi3_EDA.html`

This report provides:

- Dataset overview
- Data quality assessment
- Missing value analysis
- Distribution analysis
- Summary statistics
- Feature-level exploration
- Preliminary business insights

---

### 2. Bad Rate Summary Analysis
**File:** `smi3_BadRate_summary.ipynb`

This notebook evaluates:

- Bad rate distribution across different segments
- Risk patterns within borrower and loan characteristics
- Identification of high-risk groups
- Business interpretation of bad-rate trends

---

### 3. Potential Bias Feature Analysis
**File:** `smi3_bias_feature_analysis_funded.ipynb`

This notebook investigates:

- Potentially sensitive variables
- Feature bias assessment
- Fairness considerations
- Correlation between demographic and risk-related variables
- Identification of features requiring additional governance review

---

### 4. Feature Correlation Analysis
**File:** `smi3_feature_correlation_funded.ipynb`

This notebook analyzes:

- Relationships among predictor variables
- Multicollinearity detection
- Correlation heatmaps
- Feature dependency analysis
- Candidate feature selection considerations

---

## Key Objectives

The EDA phase supports:

- Understanding mortgage portfolio characteristics
- Identifying data quality issues
- Detecting risk-driving variables
- Evaluating potential bias in features
- Preparing inputs for machine learning models
- Supporting feature engineering decisions
